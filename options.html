Read Later — Options

Choose which quick-save entry points show up while you browse, and manage the keyboard shortcut.

Entry points

On-page floating save button
Show a small save button in the bottom-right corner of every page you visit.
Right-click "Add to Reading List" menu
Show "Add link/page to Reading List" when you right-click a page or a link.

Keyboard shortcut

Save shortcut
Default is Ctrl+Shift+S (MacCtrl+Shift+S on Mac) — instantly saves the active tab. View or change it in Chrome's own shortcut manager.

Your data

Export your reading list
Download everything you've saved as a JSON file — useful as a backup, or to move to another browser.
Import a reading list
Restore from a previous export, or import a Pocket CSV export. Duplicate URLs are skipped automatically.

Other ways to save still work regardless of these settings — the toolbar icon, the keyboard shortcut, and right-clicking the toolbar icon itself for the Reading List Manager.
