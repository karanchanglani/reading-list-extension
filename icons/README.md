# Icons

`icon16.png`, `icon32.png`, `icon48.png`, and `icon128.png` are the extension's
icon set — a "book + plus" glyph on a solid indigo background (`#4F46E5`) — used
in the toolbar, the extensions page, and the Chrome Web Store listing slot.

`icon128.png` doubles as the Web Store listing's main icon; no separate asset
is needed for that. Screenshots and (optional) promo tiles for the listing
itself aren't stored here — they're uploaded directly through the Chrome Web
Store Developer Dashboard at submission time.
